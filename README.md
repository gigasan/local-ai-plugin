# Local AI Chat

AI assistant directly inside your JetBrains IDE for working with local and cloud-based LLM models.

Local AI Chat brings AI chat directly into the editor, allowing you to work with LLMs without leaving the IDE. It supports local models via LM Studio and Ollama, as well as OpenAI API.

---

## 🚀 Features

### 💬 AI Chat Inside the IDE

Chat with LLMs directly in the editor.

- Syntax-highlighted code blocks
- Copy and collapse code snippets
- Chat history search (`Ctrl/Cmd + F`)

### 🧩 Task Compositor

Create reusable multi-step AI workflows.

- Combine text and code snippets into tasks
- Configure custom task execution order
- Store reusable Instructions and Prompts
- Import and export task configurations as JSON

### 🔌 LLM Provider Support

- LM Studio (local models)
- Ollama (local inference)
- OpenAI API

Request parameter customization:

- temperature
- stream responses
- context size
- memory options

---

## ⚙️ Installation

Install via JetBrains Marketplace:

`Settings → Plugins → Marketplace → Search: "Local AI Chat"`

Direct installation from JetBrains Plugin Repository is also supported.

---

## 📌 Usage Examples

- Select code → `Local AI → Enqueue the Task`
- Build multi-step workflows for complex analysis
- Export tasks into `task.json` and reuse them across devices
